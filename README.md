# LG 投资顾问

> 把分散的金融信息，转化为可验证、可跟踪、可推翻、可执行的条件式投资判断。

LG 投资顾问是一套以美股为主，兼顾港股、A 股、ETF 和期权研究场景的 AI 投资研究与决策辅助 Skill。

它不是简单罗列行情、财报、新闻和技术指标，而是根据用户的问题，自动判断应该先核验什么、哪些证据最重要、不同信息之间如何交叉验证，最终形成结构化的投资逻辑、风险判断和行动条件。

用户不需要指定分析步骤，只需使用自然语言提出投资问题。

---

## 它能做什么

典型使用场景包括：

- **个股研究**：NVDA 现在怎么看？
- **买入判断**：AVGO 现在适合买入吗？
- **现货接货**：闪迪多少钱可以分批接？
- **持仓诊断**：NVDA 成本 125 美元，现在该怎么处理？
- **财报分析**：NVDA 今晚公布财报，市场已经预期了什么？
- **异动解释**：MRVL 今天为什么突然大跌？
- **股票比较**：MRVL、MXL、FN、SMTC，按照当前赔率排个序。
- **行业研究**：AI 光通信现在处于什么周期？
- **新闻解读**：这条消息对 NVDA 的基本面和估值有多大影响？
- **期权分析**：这笔大额 Call 更接近方向性交易、收益增强还是风险对冲？
- **图表分析**：上传 K 线或券商截图，分析趋势、支撑、阻力和风险收益结构。
- **投资内容创作**：把分析整理成长文、简短回复、短视频口播或可转发摘要。

---

## 它如何形成判断

LG 投资顾问不会机械执行固定流水线，而是根据问题按需调用不同模块：

> 问题识别 → 数据核验 → 按需分析 → 最强反方 → 失效条件 → 情景推演 → 条件式行动方案

可能启用的分析模块包括：

- 宏观环境与市场风险偏好
- 行业周期、需求、库存与资本开支
- 商业模式、竞争优势与价值链位置
- 收入、利润率、现金流和增长质量
- 实际表现、公司指引与市场预期差
- 当前估值与价格隐含的增长假设
- 期权结构、波动率、成交量和持仓量
- 趋势、支撑、阻力与交易位置
- 催化剂、风险和投资逻辑失效条件

宏观、技术面和期权结构不是每个问题的必经步骤。Skill 会优先分析真正影响当前结论的变量。

核心原则是：

> 任何单一指标都不能独立形成投资结论。

财报超预期，不代表股价一定上涨；  
大量 Call，不代表资金一定看涨；  
低估值，不代表股票一定便宜；  
价格下跌，也不代表应该自动加仓。

## 历史判断与最新推演

LG 投资顾问会明确区分：

- **历史明确判断**：已经形成过清晰方向、动作或等待条件的观点。
- **完整历史分析**：有完整逻辑，但没有形成明确买卖动作。
- **融合通用框架**：根据投资框架形成的分析，不属于历史观点。
- **LG 投资模型推演**：依据最新事实形成的新判断。

最新推演不会被包装成历史观点，历史判断也不会被新数据静默覆盖。观点发生变化时，需要说明变化来自估值、财报、行业、政策、时间尺度还是投资目标。

## 数据准确性与能力边界

涉及“现在、今天、最新、当前价、财报、宏观事件、多少钱接、期权链”等问题时，Skill 会在回答当次重新核验数据。

关键数据会尽量说明：

- 市场、交易所和证券代码
- 数值、单位和币种
- 数据来源与截至时间
- 时区及盘前、盘中、收盘或盘后状态
- 实时、延迟、最近收盘或暂未核实
- 财报期间、会计口径和计算方法

精确盘中价格、可成交买卖价、期权链、Greeks、Call Wall、Put Wall 和 Gamma Exposure 等数据，需要交易所、券商或其他授权行情权限。

如果数据缺失、冲突、延迟或无法确认，Skill 会明确标记“暂未核实”，并降级为条件分析，不编造实时价格、精确买点、权利金或可下单合约。

图表和券商截图只能用于分析画面中能够确认的信息。缺少证券代码、周期、币种或时间戳时，不会把截图中的数字直接当成当前行情。

---

## 标准输出

一份完整分析通常包括：

1. 一句话条件式判断
2. 最新事实、准确性标签和截至时间
3. 相关历史判断
4. LG 投资模型推演
5. 关键证据与最强反方
6. 投资逻辑失效条件
7. Bull / Base / Bear 三种情景
8. 分批行动条件
9. 数据来源、计算过程和仍未核实的项目

持仓分析还会区分：

- 已有仓位还是尚未买入
- 短线交易还是中长期投资
- 当前成本和仓位
- 最大可承受回撤
- 继续持有、等待验证、分批增加、减少风险或放弃计划的条件

```text
请使用 $skill-installer 从以下 GitHub 仓库安装 LG 投资顾问 Skill：
```

安装完成后，从下一轮对话开始即可使用。

```text
用 $lg-investment-advisor 分析 NVDA 现在的投资价值。
```

## 使用示例

### 分析一只股票

```text
用 $lg-investment-advisor 分析 NVDA。

先核验最新行情和财务数据，再分析公司增长、市场预期、估值、催化剂、最强反方和失效条件，最后给出 Bull、Base、Bear 三种情景。
```

### 判断多少钱接现货

```text
用 $lg-investment-advisor 分析闪迪。

先确认证券代码、交易所和最新数据状态，再给出悲观、基准、乐观估值，以及分批接货条件、停止加仓条件和基本面失效线。
```

### 诊断已有持仓

```text
用 $lg-investment-advisor 分析我的 NVDA 持仓。

成本：125 美元
仓位：总资产的 15%
投资期限：两年
最大可承受回撤：20%

请分别给出继续持有、分批增加、减少风险和等待验证的条件。
```

### 区分历史观点与最新判断

```text
用 $lg-investment-advisor 分析这家公司。

请分别列出相关历史判断、最新事实和 LG 投资模型推演，不要把最新推演写成历史观点。
```

### 分析期权或券商截图

```text
用 $lg-investment-advisor 分析这张期权截图。

先检查标的、到期日、行权价、方向、买卖报价、时间、成交量、持仓量和价差。字段不足时列出可能解释，不要强行判断是看涨还是对冲。
```

## 使用建议

问题越具体，输出越有执行价值。

进行持仓分析时，建议同时提供：

- 市场和证券代码
- 持仓成本
- 当前仓位
- 投资期限
- 最大可承受回撤
- 是否愿意继续增加仓位

如果这些信息不完整，Skill 会提供保守、中性和积极三种条件模板，而不会默认某一种方案适合用户本人。

---

## 重要说明

LG 投资顾问是一套投资研究和决策辅助工具，不承诺收益，也不会把概率判断描述成确定结果。

它的核心价值不是替用户预测每一次涨跌，而是帮助用户建立一套能够核验、跟踪、修正和推翻的投资逻辑。
